---
title: Observation Response
description: Complete JSON schema of the ObservationResponse
---

Every `Observe()` call returns an `ObservationResponse`. Here is the full schema:

```json
{
  "type": "observation | delta",
  "system_state": {
    "document_status": "loading | interactive | complete",
    "inflight_requests": 0
  },
  "viewport": {
    "width": 1280,
    "height": 720
  },
  "visual": "<base64-encoded JPEG screenshot>",
  "spatial_tree": [
    {
      "node_id": "n42",
      "role": "button",
      "name": "Submit",
      "bounds": {
        "x": 100.5,
        "y": 200.3,
        "width": 80,
        "height": 32
      },
      "scroll_state": {
        "can_scroll_down": false,
        "can_scroll_up": false,
        "current_percentage": 0
      },
      "interactive": true,
      "value": "",
      "description": "Submit the form",
      "children": []
    }
  ],
  "tabs": [
    {
      "id": "target-id-1",
      "url": "https://example.com",
      "title": "Example",
      "active": true,
      "opener_id": ""
    }
  ],
  "page_info": {
    "url": "https://example.com",
    "title": "Example Domain",
    "platform": "web | flutter_web | android | flutter_android",
    "load_status": "loading | interactive | complete",
    "navigation_id": 1,
    "dialog_state": "none",
    "tab_count": 1,
    "extra": {}
  }
}
```

## Top-Level Fields

| Field | Type | Description |
|-------|------|-------------|
| `type` | string | `"observation"` for full tree, `"delta"` for incremental |
| `system_state` | object | Document status and network activity |
| `viewport` | object | Current viewport dimensions |
| `visual` | string | Base64-encoded JPEG screenshot |
| `spatial_tree` | array | Interactive nodes when `type` is `"observation"` |
| `delta` | object | Tree changes when `type` is `"delta"` |
| `page_info` | object | URL, title, platform, load status |
| `assertion_result` | object | Result of the last assertion (or null) |
| `action_diagnostics` | object | **Deprecated.** Use `action_result` instead. Result of the last action (or null) |
| `action_result` | object | Result of the last action with metadata, screenshot, and element highlight (or null) |
| `logs` | array | Console log entries since last observation |
| `tabs` | array | Open browser tabs (Chrome only): `id`, `url`, `title`, `active`, `opener_id` |

## TabInfo

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Target ID for use with `switch_tab` / `close_tab` |
| `url` | string | Current URL of the tab |
| `title` | string | Page title of the tab |
| `active` | bool | Whether this is the currently active tab |
| `opener_id` | string | Target ID of the tab that opened this one (popup/ad tracking) |

## SystemState

| Field | Type | Description |
|-------|------|-------------|
| `document_status` | string | `"loading"`, `"interactive"`, or `"complete"` |
| `inflight_requests` | int | Number of active network requests |

## SpatialNode

The spatial tree now includes **both interactive and structural elements** (headings, navigation, articles, tables, etc.). Agents can filter by `interactive: true` to focus on actionable elements.

| Field | Type | Description |
|-------|------|-------------|
| `node_id` | string | Unique node identifier |
| `role` | string | ARIA role (Chrome) or class name (Android) |
| `name` | string | Text label or description |
| `bounds` | object | Position and size: `x`, `y`, `width`, `height` (all float64) |
| `scroll_state` | object | `can_scroll_down`, `can_scroll_up`, `current_percentage` |
| `interactive` | bool | Whether the node is an interactive/actionable element |
| `value` | string | Current value of the element (e.g., text in an input field) |
| `description` | string | Extended description or accessibility description of the element |
| `children` | array | Nested child nodes |

## TreeDelta

Present when `type` is `"delta"`:

| Field | Type | Description |
|-------|------|-------------|
| `added` | SpatialNode[] | New nodes |
| `removed` | string[] | Node IDs of removed nodes |
| `updated` | SpatialNode[] | Nodes with changed properties |

## PageInfo

| Field | Type | Description |
|-------|------|-------------|
| `url` | string | Current URL or Android activity |
| `title` | string | Page title or screen label |
| `platform` | string | One of: `"web"`, `"flutter_web"`, `"android"`, `"flutter_android"` |
| `load_status` | string | `"loading"`, `"interactive"`, or `"complete"` |
| `navigation_id` | int64 | Increments on each URL/activity change |
| `dialog_state` | string | `"none"` or dialog type if a JavaScript dialog is open |
| `tab_count` | int | Number of open browser tabs |
| `extra` | object | Platform-specific metadata |

## AssertionResult

| Field | Type | Description |
|-------|------|-------------|
| `success` | bool | Whether the assertion passed |
| `type` | string | The assertion type that ran |
| `message` | string | Human-readable result |
| `elapsed_ms` | int64 | Evaluation time |
| `extra` | object | Type-specific data |

## ActionResult (new)

Replaces `ActionDiagnostics` with a richer structure including metadata, screenshot, and element highlight.

```json
{
  "success": true,
  "action": "click",
  "error": "",
  "elapsed_ms": 42,
  "action_metadata": {"matched_elements": 3, "clicked_index": 0},
  "screenshot": "<base64 JPEG after action>",
  "element_highlight": "<base64 JPEG with red outline on targeted element>"
}
```

| Field | Type | Description |
|-------|------|-------------|
| `success` | bool | Whether the action succeeded |
| `action` | string | The action that was executed |
| `error` | string | Error message (empty on success) |
| `elapsed_ms` | int64 | Execution time in milliseconds |
| `action_metadata` | object | Action-specific data (e.g., matched element count, clicked index) |
| `screenshot` | string | Base64-encoded JPEG of page state after the action |
| `element_highlight` | string | Base64-encoded JPEG with a red outline on the targeted element |

## ActionDiagnostics (deprecated)

Kept for backward compatibility. Prefer `ActionResult`.

| Field | Type | Description |
|-------|------|-------------|
| `action` | string | The action that was executed |
| `success` | bool | Whether the action succeeded |
| `error` | string | Error message (empty on success) |
| `elapsed_ms` | int64 | Execution time |

## ConsoleLog

| Field | Type | Description |
|-------|------|-------------|
| `level` | string | `"log"`, `"error"`, `"warn"`, `"info"`, `"debug"` |
| `message` | string | Log message text |
| `timestamp` | int64 | Epoch timestamp |
