## 0.5.0 (Current)

- Android engine with ADB + UIAutomator2 support
- Flutter platform detection (web + Android)
- Unified session management via HTTP API
- MCP bridge for AI agent integration
- YAML test runner with parallel execution
- Screenshot diffing with dHash perceptual comparison
- Video recording via CDP screencast
- Performance tracing via CDP Tracing

## 0.4.0

- Action registry for pluggable action handlers
- Enhanced selector engine (CSS, XPath, Text, Role, TestID, Placeholder)
- Wait conditions (network_idle, selector_visible, text_appear, url_match)
- Action diagnostics and assertion result tracking
- Console log capture

## 0.3.0

- Spatial tree observation with accessibility tree parsing
- Observation delta optimization (added/removed/updated)
- HTTP API observability endpoints (screenshot, DOM, console, HAR)
- Tree comparison engine

## 0.2.0

- WebSocket protocol with session management
- Multi-session support
- Headless mode configuration
- Viewport configuration

## 0.1.0

- Initial Chrome CDP engine implementation
- Basic click, type, scroll actions
- Screenshot capture
- Health check endpoint
