    import requests, base64

    s = requests.post("http://localhost:8080/api/v1/sessions",

    # Capture baseline screenshot
    baseline_resp = requests.get(f"{base}/screenshot", params={"format": "png"})
    baseline_b64 = base64.b64encode(baseline_resp.content).decode()

    # Perform some action that might change the page
    requests.post(f"{base}/actions",
        json={"action": "click", "selector": {"css": "a"}})

    # Compare against baseline
    result = requests.post(f"{base}/screenshot/diff", json={
        "expected_base64": baseline_b64,
        "tolerance": 10,
    }).json()

    print(f"Match: {result['success']}")
    print(f"Distance: {result.get('distance', 'N/A')}")
    # Distance = 0 means identical
    # Higher distance = more visual difference

    requests.delete(f"{base}")

## How It Works

The screenshot comparison uses a **dHash (difference hash)** algorithm:

1. Both images are resized to 9×8 pixels and converted to grayscale
2. Each pixel is compared to its neighbor → 64-bit hash
3. The **Hamming distance** between the two hashes is the result
4. Distance `0` = identical; higher values = more differences

## Tolerance Guidelines

| Tolerance | Use Case |
|-----------|----------|
| 0 | Exact pixel match (anti-aliasing may cause false failures) |
| 5-10 | Minor rendering differences (font rendering, OS differences) |
| 10-20 | Accept slight layout shifts |
| 20+ | Only catch major visual changes |

## Best Practices

1. **Take baseline screenshots in a controlled environment** (same OS, same fonts)
2. **Use tolerance** to account for rendering differences
3. **Store baseline images** alongside your test code
4. **Review visual diffs manually** when they fail
5. Screenshot testing complements — does not replace — functional assertions
