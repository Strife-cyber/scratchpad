The WebSocket API provides real-time, persistent connection automation. Each connection creates an isolated session.

## Endpoints

| Path | Engine | Description |
|------|--------|-------------|
| `ws://localhost:8080/ws` | Chrome | Browser automation |
| `ws://localhost:8080/ws/android` | Android | Device automation |

## Protocol Flow

```
Client                          Server
  │                               │
  │────  Connect  ───────────────>│
  │<─── {"sessionId":"..."} ─────│
  │                               │
  │── {"type":"navigate","data":{...}} ──>│
  │<─── ObservationResponse ─────│
  │                               │
  │── {"type":"action","data":{...}} ───>│
  │<─── ObservationResponse ─────│
  │                               │
  │── {"type":"observe"} ────────>│
  │<─── ObservationResponse ─────│
  │                               │
  │── {"type":"resize","data":{...}} ──>│
  │<─── ObservationResponse ─────│
  │                               │
  │──── Disconnect ──────────────>│
```

## Message Types

All messages use a typed **Envelope** with a `"type"` discriminator field. The envelope structure is:

```json
{
  "type": "navigate | action | observe | resize",
  "data": { ... }
}
```

| Type | Purpose |
|------|---------|
| `"navigate"` | Navigate to a URL or launch an app |
| `"action"` | Perform an action (click, type, scroll, etc.) |
| `"observe"` | Trigger an observation without performing an action |
| `"resize"` | Resize the browser viewport |

### navigate

Sent first to navigate to a URL or launch an app:

```json
{
  "type": "navigate",
  "data": {
    "url": "https://example.com",
    "viewport": {"width": 1280, "height": 720}
  }
}
```

### action

Sent to perform an action:

```json
{
  "type": "action",
  "data": {
    "action": "click",
    "selector": {"css": "#submit-btn"},
    "timeout_ms": 10000
  }
}
```

### observe

Send an observe message to trigger an observation without performing an action:

```json
{
  "type": "observe"
}
```

### resize

Resize the browser viewport:

```json
{
  "type": "resize",
  "data": {
    "width": 1280,
    "height": 720
  }
}
```

> **Backward compatibility:** Legacy `{}` (empty object) still works for observe-only usage.

### Legacy Empty Message

Send an empty JSON object `{}` to trigger an observation without performing an action (deprecated; prefer `{"type": "observe"}`).

## Delta Optimization

Repeated observations can return **deltas** instead of full spatial trees to reduce bandwidth:

```json
{
  "type": "delta",
  "delta": {
    "added": [{"node_id": "n3", "role": "dialog", ...}],
    "removed": ["n1"],
    "updated": [{"node_id": "n2", "role": "button", "name": "Updated Text", ...}]
  },
  "page_info": {...},
  "system_state": {...},
  "visual": "<base64 JPEG>"
}
```

When `type` is `"delta"`, `spatial_tree` is omitted and `delta` contains only the changes.

## Auto-Wait

Selectors-based actions (click, type, hover, double_click, right_click, drag_drop) now **auto-wait** for the target element before executing. This means the engine polls at 50ms intervals for a visible and enabled element matching the selector, up to the configured timeout.

- If the element is found but not visible, the error includes a hint: *"try scroll_into_view"*
- After an action completes, the engine briefly waits for page stability (network idle + 100ms of quiet time)

## Python Example

```python
import json
import websockets

async def automate():
    async with websockets.connect("ws://localhost:8080/ws") as ws:
        # Receive session ID
        handshake = json.loads(await ws.recv())
        print(f"Session: {handshake['sessionId']}")

        # Navigate using typed envelope
        await ws.send(json.dumps({
            "type": "navigate",
            "data": {"url": "https://example.com", "viewport": {"width": 1280, "height": 720}}
        }))
        obs = json.loads(await ws.recv())
        print(f"Title: {obs['page_info']['title']}")

        # Click using typed envelope
        await ws.send(json.dumps({
            "type": "action",
            "data": {"action": "click", "x": 100, "y": 200}
        }))
        obs = json.loads(await ws.recv())

        # Observe only using typed envelope (or legacy {})
        await ws.send(json.dumps({"type": "observe"}))
        obs = json.loads(await ws.recv())
```

## Error Handling

If an action fails, the WebSocket returns an **ErrorResponse** with screenshot context:

```json
{
  "type": "error",
  "error": {
    "message": "Failed to click element: element not visible",
    "code": "ELEMENT_NOT_VISIBLE",
    "elapsed_ms": 1042
  },
  "screenshot": "<base64 JPEG of page state at time of error>",
  "page_info": {
    "url": "https://example.com",
    "title": "Example Domain"
  }
}
```

An `ErrorResponse` is **always** sent on failure. The error includes a screenshot of the page state so agents can inspect what went wrong. The connection remains open for further commands.

## Session Management

Sessions auto-expire after **5 minutes of inactivity** (configurable). A background cleanup loop runs every 30 seconds to evict stale sessions. Any WebSocket message or HTTP API call resets the `lastActivity` timer for the session.

| Setting | Default | Description |
|---------|---------|-------------|
| `SCRATCHPAD_SESSION_IDLE_TIMEOUT` | `5m` | Max idle time before session eviction |
| `SCRATCHPAD_SESSION_CLEANUP_INTERVAL` | `30s` | How often cleanup loop runs |

### Keepalive

The WebSocket connection uses ping/pong keepalive to detect disconnection:
- Ping sent every **10 seconds**
- Deadline of **15 seconds** before connection is considered dead
