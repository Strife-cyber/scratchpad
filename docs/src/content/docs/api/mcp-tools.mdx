Scratchpad includes a built-in MCP (Model Context Protocol) server, allowing AI agents like Claude to control browsers and devices directly.

> **Concurrent safety:** The MCP server uses mutex-protected write-then-read cycles, making concurrent tool calls safe. Dial timeout is 10 seconds, read timeout is 30 seconds.

## Starting the MCP Bridge

```bash
scratchpad-cli mcp

# Or with a custom engine URL:
scratchpad-cli mcp --engine-url ws://localhost:8080/ws --name "scratchpad-mcp" --version "1.0.0"
```

This starts an MCP server over stdio. Configure your AI agent to launch this as an MCP tool.
The engine server (`make run`) must already be running; the bridge connects to it on startup.

| Environment variable | Purpose |
|----------------------|---------|
| `SCRATCHPAD_URL` | Engine WebSocket URL when `--engine-url` is not given (default `ws://localhost:8080/ws`) |
| `SCRATCHPAD_TOKEN` | Sent as `Authorization: Bearer` when the server was started with a token |
| `SCRATCHPAD_MCP_SCREENSHOTS` | `always` attaches a page screenshot (and the element highlight) to every action and `browser_navigate` response. By default only `browser_observe` and `browser_screenshot` return images; action responses carry the text outline |
| `SCRATCHPAD_MCP_TOOLS` | Optional tool groups to register, comma-separated: `android` (the `android_*` tools), `advanced` (`browser_action`, `browser_switch_to_iframe`, `browser_switch_to_main_frame`), or `all`. Off by default to keep the tool list small |
| `CHROME_PATH` | Set on the **server**: the Chrome/Chromium binary to launch |

## Tools

### browser_navigate

Loads a URL in the browser (or launches an Android app):

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `url` | string | Yes | URL to navigate to or Android package name |

**Returns:** ObservationResponse (text description + screenshot)

### browser_observe

Captures the current page state:

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| _(none)_ | | | No parameters needed |

**Returns:** Text summary of page state + full JSON + JPEG screenshot as image content.

### browser_action

Opt-in (`SCRATCHPAD_MCP_TOOLS=advanced`). Executes any action on the current page. Selector-based actions (click, type, hover, double_click, right_click, drag_drop) **auto-wait** for the target element — the engine polls at 50ms intervals until the element is visible and enabled, up to the configured timeout.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `action` | string | Yes | Action type: `click`, `type`, `scroll`, `wait`, etc. |
| `selector` | object | No | Element selector (`css`, `xpath`, `text`, `role`, etc.) |
| `x`, `y` | number | No | Click coordinates |
| `text` | string | No | Text for type action |
| `delta_x`, `delta_y` | number | No | Scroll amounts |
| `timeout_ms` | number | No | Action timeout |

Any field from `ActionRequest` can be passed. Supports all action types including `switch_tab`, `close_tab`, `check`, `uncheck`, `submit_form`, `fill_form`, `dismiss_modal`.

### browser_assert

Verifies page state:

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `assertion` | object | Yes | Assertion request (see below) |

**Assertion object:**

```json
{
  "type": "text_contains",
  "selector": {"css": "h1"},
  "text": "Welcome",
  "timeout_ms": 5000
}
```

### browser_list_tabs

Lists all open browser tabs. Useful for detecting tabs opened by ads or links.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| _(none)_ | | | No parameters needed |

**Returns:** Observation with `tabs` array containing tab `id`, `url`, `title`, `active`, `opener_id`.

### browser_switch_tab

Switches to a different browser tab by ID.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `tab_id` | string | Yes | Tab ID from `browser_list_tabs` |

### browser_close_tab

Closes a browser tab by ID.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `tab_id` | string | Yes | Tab ID from `browser_list_tabs` |

### browser_dismiss_modal

Dismisses popups, overlays, cookie banners, and interstitial dialogs.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `strategy` | string | No | `"auto"` (default), `"press_escape"`, `"click_outside"`, or `"click_button"` |

### browser_check

Checks a checkbox or radio button.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `selector` | object | Yes | CSS selector for the checkbox/radio |

### browser_uncheck

Unchecks a checkbox or radio button.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `selector` | object | Yes | CSS selector for the checkbox/radio |

### browser_submit_form

Submits a form by selector.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `selector` | object | Yes | CSS selector for the form or a child element |

### browser_fill_form

Fills multiple form fields at once.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `fields` | array | Yes | Array of `{selector, value}` objects |

## Using with Claude Desktop

Add to your `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "scratchpad": {
      "command": "scratchpad-cli",
      "args": ["mcp", "--engine-url", "ws://localhost:8080/ws"]
    }
  }
}
```

## Tool Response Structure

Browser tools return a text summary; `browser_observe` (and every action when
`SCRATCHPAD_MCP_SCREENSHOTS=always`) also attaches the page screenshot:

```text
State: document complete
Page: http://localhost:3000/login | Login | web
Action: ✅ click (57ms)
Nodes: 12
Elements: (pass a ref as handle_id to act on that element)
- heading "Sign in" ref=13
- textbox "Username" value="alice" ref=4
- button "Log in" ref=7
- paragraph: Welcome, alice
```

Every interactive, named or text-bearing node is listed in page order. Pass a
`ref` as `handle_id` to act on that element, or use the same role and name as a
selector (`{"role":"textbox","name":"Username"}`). `browser_observe` with
`include_raw_json: true` appends the full JSON observation.

Engine errors (no element matched, navigation failed, …) come back as a result
flagged `isError: true` whose text is the JSON error envelope (`code`,
`message`, `hint`). Soft failures, such as a wait or assertion that did not
pass, are normal results marked `❌` so the page state is still attached.
