## Web Navigation

Send an `InitializeRequest` with a URL to navigate the browser:

<Tabs syncKey="lang">
  <TabItem label="Python">
    ```python
    import requests

    session = requests.post("http://localhost:8080/api/v1/sessions",
        json={"platform": "web"}).json()
    sid = session["sessionId"]

    obs = requests.post(
        f"http://localhost:8080/api/v1/sessions/{sid}/actions",
        json={"action": {"type": "navigate", "url": "https://example.com"}},
    ).json()

    print(obs["page_info"]["url"])       # "https://example.com"
    print(obs["page_info"]["title"])      # "Example Domain"
    print(obs["page_info"]["load_status"]) # "complete"
    print(obs["page_info"]["navigation_id"]) # 1
    ```
  </TabItem>

## Android Navigation

On Android, `Navigate` launches an app by package name or opens a URL:

```json
{
  "action": {
    "type": "navigate",
    "url": "com.example.app"     // Launch app by package name
  }
}
```

If the URL contains `://` it's opened in the browser; otherwise it's treated as an Android package name and launched via `adb shell monkey -p <package> 1`.

## PageInfo Response

Every observation includes a `page_info` field:

| Field | Type | Description |
|-------|------|-------------|
| `url` | string | Current page URL or Android activity |
| `title` | string | Page title or screen label |
| `platform` | string | `"web"`, `"flutter_web"`, `"android"`, `"flutter_android"` |
| `load_status` | string | `"loading"`, `"interactive"`, `"complete"` |
| `navigation_id` | int64 | Increments on each URL/activity change |
| `extra` | object | Platform-specific metadata |

## SPA Navigation

For single-page applications, the engine detects URL changes even without full page loads. Each URL change increments `navigation_id`, making it easy to track client-side routing.
